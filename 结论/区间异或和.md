# 区间异或和

## 题目
给定一个数组 $a$，求区间 $[l,r]$ 的异或和，即 $a[l] \oplus a[l+1] \oplus \cdots \oplus a[r]$。

## 思路
我们可以使用前缀异或数组来快速计算任意区间的异或和。定义前缀异或数组 $pxor$，其中 $pxor[i] = a[0] \oplus a[1] \oplus \cdots \oplus a[i]$。那么区间 $[l,r]$ 的异或和可以表示为：
$$
a[l] \oplus a[l+1] \oplus \cdots \oplus a[r] = pxor[r] \oplus pxor[l-1]
$$
这样，我们只需要 $O(1)$ 的时间复杂度就可以计算出任意区间的异或和。
## 结论
又由异或的性质可知，对于任意整数 $n$，$0 \oplus 1 \oplus 2 \oplus \cdots \oplus n$ 的值可以通过以下规律计算：
- 如果 $n \mod 4 = 0$，则结果为 $n$
- 如果 $n \mod 4 = 1$，则结果为 $1$
- 如果 $n \mod 4 = 2$，则结果为 $n + 1$
- 如果 $n \mod 4 = 3$，则结果为 $0$

## 实现
```cpp
int xor_0_to_n(int n) {
    if (n % 4 == 0) return n;
    if (n % 4 == 1) return 1;
    if (n % 4 == 2) return n + 1;
    return 0;
}

int xor_l_to_r(int l, int r) {
    return xor_0_to_n(r) ^ xor_0_to_n(l - 1);
}
```
